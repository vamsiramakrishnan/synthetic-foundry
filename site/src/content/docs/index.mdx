Worldloom is for developers testing retrieval, extraction, temporal questions,
and agent workflows. The repository is `synthetic-foundry`; the Python package
and command are `worldloom`. It is pre-release and installs from source.

## First result: files you can open, answers you can check

After [installation](/synthetic-foundry/getting-started/installation/):

```bash
worldloom build --seed 8128 --incident --narrate --out ./corpus
worldloom render ./corpus -f xlsx -f docx -f pptx -f pdf -f markdown
worldloom validate ./corpus
worldloom evaluate ./corpus --retriever both
```

This path uses deterministic sample prose and no model service. The default
example covers a retailer's month-end close and an incident. It is one episode,
not a complete retailer's operating history.

| Open | Inspect |
|---|---|
| `artifacts/` | Rendered documents and workbooks |
| `facts.jsonl` | The facts those artifacts may claim |
| `evals.jsonl` | Questions and their evidence bindings |
| `generation-ledger.jsonl` | Accepted authored content used for replay |
| `world.json` | Company state and recorded recipe |

[Run the quickstart](/synthetic-foundry/getting-started/quickstart/) or inspect
[the corpus format](/synthetic-foundry/reference/corpus-anatomy/).

## Build for the failure you want to measure

| Evaluation | Corpus ingredients |
|---|---|
| Cited retrieval | Supporting evidence, distractors, and answer bindings |
| Document and spreadsheet extraction | Reconciled values across tables and narrative claims |
| Temporal reasoning | Events, supersession, and knowledge cutoffs |
| Business-system workflows | Connector records, entity relationships, and trace checks |
| Realistic document reading | Agent-authored prose accepted against factual constraints |

Choose business processes, time depth, entity scale, and artifact density
separately. Increasing headcount alone does not create a broader company
history. [Design an enterprise corpus](https://github.com/vamsiramakrishnan/synthetic-foundry/blob/main/docs/enterprise-corpus.md).

## Facts constrain the writer and the renderer

The world establishes identities, amounts, events, and chronology. Artifact
plans select facts and audiences. Writers propose prose. Renderers materialize
the resolved representation into file formats.

Validation checks declared relationships: a total reconciles, an author exists,
a cited fact is known at the stated time, and an evaluation answer has evidence.
Intentional defects can be recorded rather than silently treated as truth.

A coherent corpus can still be easy to retrieve from, repetitive, or stylistically
weak. Measure those properties separately. The deterministic narrator is a
first-run and replay aid. [Use your agent as the writer](/synthetic-foundry/guides/narration/)
when prose quality matters.
