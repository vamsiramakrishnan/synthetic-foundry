Worldloom generates the enterprise before it generates the files. It builds a
company, its people, its systems, and its facts from a seed. It then projects
that state into XLSX, DOCX, PDF, PPTX, Markdown, and business-system bundles.
Every document in the corpus can be checked against the same fact ledger.

The renderers never decide what is true. Each one reads a single resolved
`ArtifactIR` and spells it in a different file grammar. That is why the PDF
and the workbook agree without coordinating.
